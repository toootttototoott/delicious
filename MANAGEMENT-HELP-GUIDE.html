Platform Guide

Management Help Guide

This guide is intended for management, operational, and rollout users who need to understand how to access and use the platform day to day.

What the Platform Does

The platform manages venue-based bookings across companies, establishments, and seat-count calendars.

  • Internal management logins with role-based access
  • Booking calendar and day-by-day availability management
  • Manual booking creation, editing, and cancellation
  • Booking search and reporting
  • Company, venue, and seat-count configuration
  • Public booking widget and standalone booking page setup
  • Admin-only AI-assisted theme editing for the widget and booking page

1. Access and User Roles

Users sign in with an email address and password.

  • Admin: full access to users, settings, venues, booking tools, widget setup, styling, and system configuration.
  • Manager: venue-scoped access, booking management, reporting, staff creation, and booking-day closures.
  • Staff: venue-scoped day-to-day booking and booking search access.

Staff users cannot run reports or manage booking-day closures.

2. Signing In

  1. Open the platform login page.
  2. Enter your assigned email address and password.
  3. After sign-in, the system will take you to the appropriate management view based on your role.

Password reset

  1. Select Forgot password.
  2. Enter the email address linked to the account.
  3. Open the reset email.
  4. Follow the link and choose a new password.

3. Main Navigation

  • Settings: admin-only full management area.
  • Widget: public booking widget preview.
  • Widget Setup: choose the live company, establishment, and seat-count source.
  • Theme Editor: edit or generate booking widget CSS.
  • Page View Editor: edit or generate the standalone booking page structure and CSS.

Managers and staff are automatically directed to their scoped management workspace rather than the full admin area.

4. Daily Booking Workflow

Start of day

  1. Sign in at the start of service.
  2. Review today’s bookings and remaining availability.
  3. Confirm important notes or larger bookings.
  4. Update the calendar as calls, emails, or manual requests come through.

Review the calendar

Users select the company, establishment, and seat-count calendar. The calendar then shows open and closed dates, bookable days, time-slot availability, and existing bookings for the selected day.

Create a Booking

  1. Open the required date in the booking calendar.
  2. Select the time slot.
  3. Enter party size, guest details, phone, and notes if needed.
  4. Save the booking.

If email delivery is configured, a confirmation email can be sent automatically after the booking is created.

Edit or Cancel

To edit a booking, open it from the day view or booking search, update the details, and save the changes.

To cancel a booking, open the booking record and delete it.

5. Searching for Existing Bookings

The booking workspace includes search so staff and managers can locate bookings quickly by guest details such as name, email, or phone.

This is useful when:

  • A guest calls to make changes
  • Staff need to confirm whether a booking already exists
  • A team member needs to find a booking without manually browsing the calendar

6. Booking Reports

Booking reports are available to admins and managers.

Reports can be filtered by:

  • Date range
  • Time range
  • Seat-count calendar

Preset ranges are available for Today, This week, and This month, and reports can be exported to CSV.

7. Closing or Reopening Booking Days

Admins and managers can stop bookings for a specific day where required, for example for private events, public holidays, or operational capacity limits.

Staff users do not have access to this control.

8. User and Access Management

Admins

  • Create users
  • Edit users
  • Delete users
  • Assign roles
  • Assign company and establishment access

Managers

  • Create staff users for their assigned establishment
  • Edit staff users for that establishment
  • Delete staff users for that establishment

Managers cannot create other managers or admins.

9. Company, Establishment, and Capacity Setup

Admins can maintain the platform structure through the company management area.

  • Companies: company name and enquiry email address
  • Establishments: the venues that belong to a company
  • Seat counts: maximum seat capacity, guest visit duration, and maximum online booking party size

This setup allows separate calendars for rooms, spaces, service areas, or venue sections.

10. Opening Hours

Admins can define opening hours for each establishment by weekday. Each day can be marked open or closed, and open days require opening and closing times. Bookings are only offered within configured hours.

11. Booking Confirmation Email Testing

Admins can test the booking confirmation email setup directly from the settings area to verify the SMTP connection, the sending address, and the guest-facing layout before rollout.

12. Widget Setup

The widget setup area is used to choose which live booking source is exposed on the public-facing website.

  • Choose company
  • Choose establishment
  • Choose seat-count calendar

Once selected, the platform provides the widget URL, standalone booking page URL, and embed code for the external website.

13. Public Booking Experience

The public-facing booking experience is available in two formats:

  • Embedded widget
  • Standalone page view

Guests can select a date and time, enter booking details, and submit a booking. If the requested party size is above the configured online booking limit, the guest is directed to submit an enquiry instead.

14. Theme Editor

The Theme Editor is an admin-only tool for the embedded booking widget.

  • Manual CSS editing
  • AI-assisted CSS generation
  • Attachment uploads for design references
  • Saved prompt templates
  • Preview before publishing

15. Page View Editor

The Page View Editor applies to the standalone booking page.

  • Manage page content JSON
  • Manage page-specific CSS
  • Generate both content structure and styling
  • Preview before saving

16. Prompt Library

Admins can save prompt templates in the editor areas to reuse preferred design direction, brand instructions, or venue-specific styling requests.

17. Suggested Rollout Process

  1. Create admin access.
  2. Set up companies and establishments.
  3. Create seat-count calendars and opening hours.
  4. Add manager and staff users.
  5. Confirm booking confirmation email settings.
  6. Test manual booking creation and editing.
  7. Test reporting and booking-day closure workflows.
  8. Confirm widget or page-view setup for the live site.
  9. Provide team training and issue test logins.

18. Suggested Team Training Topics

  • Signing in and password reset
  • Using the booking calendar
  • Creating, editing, and cancelling bookings
  • Searching for guest bookings
  • Understanding availability and remaining capacity
  • When to use close-day controls
  • How manager and staff permissions differ

19. Support and Walkthrough

Test users can be created for review and training purposes.

If helpful, a one-on-one Microsoft Teams walkthrough can also be arranged to run through the platform with the team live, answer operational questions, and confirm the rollout workflow.
